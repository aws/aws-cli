**To delete a network ACL**

The following ``delete-network-acl`` example deletes the specified network ACL. ::

    aws ec2 delete-network-acl \
        --network-acl-id acl-5fb85d36

This command produces no output.

For more information, see `Delete a network ACL for your VPC <https://docs.aws.amazon.com/vpc/latest/userguide/delete-network-acl.html>`__ in the *Amazon VPC User Guide*.
