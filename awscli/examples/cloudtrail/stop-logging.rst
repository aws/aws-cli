**To stop logging a trail**

The following ``stop-logging`` example turns off logging for ``Trail1``. ::

    aws cloudtrail stop-logging \
        --name Trail1

This command produces no output.

For more information, see `Turning off logging for a trail <https://docs.aws.amazon.com/awscloudtrail/latest/userguide/cloudtrail-turning-off-logging.html>`__ in the *AWS CloudTrail User Guide*.
