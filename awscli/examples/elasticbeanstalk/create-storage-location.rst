**To create a storage location**

The following ``create-storage-location`` example creates a storage location in Amazon S3. ::

    aws elasticbeanstalk create-storage-location

Output::

    {
        "S3Bucket": "elasticbeanstalk-us-west-2-0123456789012"
    }

For more information, see `Using Elastic Beanstalk with Amazon S3 <https://docs.aws.amazon.com/elasticbeanstalk/latest/dg/AWSHowTo.S3.html>`__ in the *AWS Elastic Beanstalk Developer Guide*.
