**To delete a VPN connection**

The following ``delete-vpn-connection`` example deletes the specified VPN connection. ::

    aws ec2 delete-vpn-connection \
        --vpn-connection-id vpn-40f41529

This command produces no output.

For more information, see `Delete an AWS Site-to-Site VPN connection <https://docs.aws.amazon.com/vpn/latest/s2svpn/delete-vpn-connection.html>`__ in the *AWS Site-to-Site VPN User Guide*.
