**To delete a workflow run**

The following ``delete-run`` example deletes a run with ID ``1234567``. ::

    aws omics delete-run \
        --id 1234567

This command produces no output.

For more information, see `Delete a run in HealthOmics <https://docs.aws.amazon.com/omics/latest/dev/deleting-runs.html>`__ in the *AWS HealthOmics User Guide*.
