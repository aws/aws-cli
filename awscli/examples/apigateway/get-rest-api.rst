**To get information about an API**

The following ``get-rest-api`` example gets information about the specified REST API. ::

    aws apigateway get-rest-api \
        --rest-api-id 1234123412

Output::

    {
        "name": "myAPI",
        "id": "o1y243m4f5",
        "createdDate": 1453416433
    }
