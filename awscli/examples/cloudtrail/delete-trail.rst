**To delete a trail**

The following ``delete-trail`` example deletes a trail named ``Trail1``. ::

    aws cloudtrail delete-trail \
        --name Trail1

This command produces no output.

For more information, see `Managing trails with the AWS CLI <https://docs.aws.amazon.com/awscloudtrail/latest/userguide/cloudtrail-additional-cli-commands.html#cloudtrail-delete-trail-cli>`__ in the *AWS CloudTrail User Guide*.
