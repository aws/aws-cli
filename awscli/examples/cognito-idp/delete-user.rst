**To delete a user**

The following ``delete-user`` example deletes a user. ::

    aws cognito-idp delete-user \
        --access-token ACCESS_TOKEN

This command produces no output.

For more information, see `Managing users in your user pool <https://docs.aws.amazon.com/cognito/latest/developerguide/managing-users.html>`__ in the *Amazon Cognito Developer Guide*.
