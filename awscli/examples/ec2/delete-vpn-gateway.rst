**To delete a virtual private gateway**

The following ``delete-vpn-gateway`` example deletes the specified virtual private gateway. ::

    aws ec2 delete-vpn-gateway \
        --vpn-gateway-id vgw-9a4cacf3

This command produces no output.

For more information, see `Detach and delete a virtual private gateway in AWS Site-to-Site VPN <https://docs.aws.amazon.com/vpn/latest/s2svpn/delete-vgw.html>`__ in the *AWS Site-to-Site VPN User Guide*.
