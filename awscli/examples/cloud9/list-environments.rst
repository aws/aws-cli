**To get a list of available AWS Cloud9 development environment identifiers**

The following ``list-environments`` example gets a list of available AWS Cloud9 development environment identifiers. ::

    aws cloud9 list-environments

Output::

    {
        "environmentIds": [
            "685f892f431b45c2b28cb69eadcdb0EX",
            "1980b80e5f584920801c09086667f0EX"
        ]
    }

For more information, see `Working with environments in AWS Cloud9 <https://docs.aws.amazon.com/cloud9/latest/user-guide/environments.html>`__ in the *AWS Cloud9 User Guide*.
