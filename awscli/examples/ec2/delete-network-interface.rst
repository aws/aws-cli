**To delete a network interface**

The following ``delete-network-interface`` example deletes the specified network interface. ::

    aws ec2 delete-network-interface \
        --network-interface-id eni-e5aa89a3

This command produces no output.

For more information, see `Delete a network interface <https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/delete_eni.html>`__ in the *Amazon EC2 User Guide*.
