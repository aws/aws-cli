**To delete a snapshot**

The following ``delete-snapshot`` example deletes a snapshot with the snapshot ID of ``snap-1234567890abcdef0``. ::

    aws ec2 delete-snapshot \
        --snapshot-id snap-1234567890abcdef0

This command produces no output.

For more information, see `Delete an Amazon EBS snapshot <https://docs.aws.amazon.com/ebs/latest/userguide/ebs-deleting-snapshot.html>`__ in the *Amazon EBS User Guide*.
