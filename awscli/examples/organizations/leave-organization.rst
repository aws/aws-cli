**To leave an organization as a member account**

The following ``leave-organization`` example requests that a member account leave the organization it is currently a member of. ::

    aws organizations leave-organization

This command produces no output.

For more information, see `Leaving an organization from a member account with AWS Organizations <https://docs.aws.amazon.com/organizations/latest/userguide/orgs_manage_accounts_leave-as-member.html>`__ in the *AWS Organizations User Guide*.
