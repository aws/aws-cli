**To delete a run group**

The following ``delete-run-group`` example deletes a run group with ID ``1234567``. ::

    aws omics delete-run-group \
        --id 1234567

This command produces no output.

For more information, see `Using HealthOmics run groups <https://docs.aws.amazon.com/omics/latest/dev/creating-run-groups.html>`__ in the *AWS HealthOmics User Guide*.
