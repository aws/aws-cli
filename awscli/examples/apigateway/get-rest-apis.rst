**To get a list of REST APIs**

The following ``get-rest-apis`` example gets a list of REST APIs. ::

    aws apigateway get-rest-apis

Output::

    {
        "items": [
            {
                "createdDate": 1438884790,
                "id": "12s44z21rb",
                "name": "My First API"
            }
        ]
    }
