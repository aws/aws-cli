**To delete a queue**

The following ``delete-queue`` example deletes the specified queue. ::

    aws sqs delete-queue \
        --queue-url https://sqs.us-west-2.amazonaws.com/80398EXAMPLE/MyNewerQueue

This command produces no output.

For more information, see `Deleting an Amazon SQS queue <https://docs.aws.amazon.com/AWSSimpleQueueService/latest/SQSDeveloperGuide/step-delete-queue.html>`__ in the *Amazon Simple Queue Service Developer Guide*.
