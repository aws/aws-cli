**To delete a game session queue**

The following ``delete-game-session-queue`` example deletes a specified game session queue. ::

    aws gamelift delete-game-session-queue \
        --name MegaFrogRace-NA 

This command produces no output.

For more information, see `Configure game session placement <https://docs.aws.amazon.com/gameliftservers/latest/developerguide/queues-intro.html>`__ in the *Amazon GameLift Servers Developer Guide*.
