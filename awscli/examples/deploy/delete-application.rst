**To delete an application**

The following ``delete-application`` example deletes the specified application that is associated with the user's AWS account. ::

    aws deploy delete-application \
        --application-name WordPress_App

This command produces no output.

For more information, see `Delete an application in CodeDeploy <https://docs.aws.amazon.com/codedeploy/latest/userguide/applications-delete.html>`__ in the *AWS CodeDeploy User Guide*.
