**To remove all permissions from a specified resource**

The following ``remove-all-resource-permissions`` example removes all permissions from the specified resource. ::

    aws workdocs remove-all-resource-permissions \
        --resource-id 1ece93e5fe75315c7407c4967918b4fd9da87ddb2a588e67b7fdaf4a98fde678

This command produces no output.
