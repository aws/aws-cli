**To delete a pipeline**

The following ``delete-pipeline`` example deletes the specified pipeline. ::

    aws datapipeline delete-pipeline \
        --pipeline-id df-00627471SOVYZEXAMPLE

This command produces no output.

For more information, see `Deleting Your Pipeline <https://docs.aws.amazon.com/datapipeline/latest/DeveloperGuide/dp-manage-pipeline-delete-console.html>`__ in the *AWS Data Pipeline Developer Guide*.
