**To list the available detectors in the current region**

The following ``list-detectors`` example lists the available detectors in your current AWS region. ::

    aws guardduty list-detectors 

Output::

    {
        "DetectorIds": [
            "12abc34d567e8fa901bc2d34eexample"
        ]
    }

For more information, see `Concepts and key terms in Amazon GuardDuty <https://docs.aws.amazon.com/guardduty/latest/ug/guardduty_concepts.html>`__ in the *Amazon GuardDuty User Guide*.
