**To delete a Cost and Usage budget**

The following ``delete-budget`` example deletes the specified Cost and Usage budget. ::

    aws budgets delete-budget \
        --account-id 123456789012 \
        --budget-name "Example Budget"

This command produces no output.

For more information, see `Deleting a budget <https://docs.aws.amazon.com/cost-management/latest/userguide/budgets-delete.html>`__ in the *AWS Cost Management User Guide*.
